Executando localmente

Pré-requisitos

É necessário ter instalado:

* Node.js
* npm

Clone o repositório

git clone <URL_DO_REPOSITORIO>

Entre na pasta

cd <NOME_DO_REPOSITORIO>

Instale as dependências

npm install

Inicie o projeto

npm run dev

O Vite fornecerá o endereço local para acessar a aplicação.
